# Taste of Home

**Taste of Home** is a full-stack e-commerce web application for exploring and purchasing food products online.

Built with **FastAPI, SQLAlchemy, Jinja2, and SQLite**, the project includes user authentication, OTP verification, shopping cart, checkout, order management, and an admin dashboard.

## Features

* User registration, login, and OTP verification
* Product browsing and shopping cart
* Checkout and order placement
* Order management
* Admin dashboard

## Tech Stack

* **Backend:** FastAPI, Python
* **Database:** SQLite, SQLAlchemy
* **Frontend:** HTML, CSS, Jinja2
* **API Integration:** 2Factor OTP

## Run Locally

```bash
git clone <your-repository-url>
cd taste-of-home
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000` in your browser.
